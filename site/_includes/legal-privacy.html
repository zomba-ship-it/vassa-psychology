Политика конфиденциальности и обработки персональных данных

О том, какие данные могут обрабатываться, для чего они нужны и как обеспечивается конфиденциальность

2. Какие данные могут обрабатываться

При обращении за консультацией и в процессе психологической работы могут обрабатываться:

  • Имя или псевдоним — для обращения и организации встреч.
  • Контактные данные — адрес электронной почты, номер телефона, имя пользователя или номер в мессенджерах.
  • Информация об оплате — сведения, необходимые для подтверждения оплаты и исполнения налоговых обязательств.
  • Информация, добровольно сообщённая в процессе консультаций — личные переживания, жизненные обстоятельства, отношения, эмоциональное состояние и другие сведения, необходимые для психологической работы.

Клиент самостоятельно определяет, какой информацией делиться. Предоставлять избыточные личные сведения не требуется.

3. Для чего используются данные

Персональные данные используются исключительно для:

  • организации и проведения психологических консультаций;
  • согласования времени и формата встреч;
  • связи по вопросам записи, переноса и оплаты;
  • ведения необходимых рабочих записей;
  • обеспечения профессиональной преемственности психологической работы;
  • исполнения требований законодательства.

Данные не используются для продажи, рекламных рассылок и маркетинговых целей без отдельного согласия клиента.

Для записи и общения с психологом клиент может самостоятельно выбрать удобный способ связи:

  • Telegram;

Оператор не продаёт и не передаёт личную информацию клиентов посторонним лицам. При этом техническая обработка данных может осуществляться соответствующими цифровыми платформами в соответствии с их политиками конфиденциальности.

Содержание психологических консультаций является конфиденциальным. При обсуждении профессиональных случаев на супервизии информация используется в обезличенном виде, без раскрытия личности клиента. Раскрытие информации без согласия клиента возможно только в случаях, предусмотренных законодательством.

5. Сроки хранения данных

Персональные данные хранятся только в течение срока, необходимого для целей их обработки, с учётом требований законодательства:

  • контактные данные — на период взаимодействия и до достижения целей обработки;
  • рабочие записи — в течение срока, необходимого для профессиональной деятельности;
  • платёжные и налоговые документы — в сроки, установленные законодательством.

После достижения целей обработки данные удаляются или уничтожаются, если отсутствуют законные основания для дальнейшего хранения.

6. Права клиента

Клиент имеет право:

  • узнать, какие его персональные данные обрабатываются;
  • запросить информацию о целях и способах обработки;
  • потребовать исправления неточных сведений;
  • отозвать согласие на обработку персональных данных;
  • потребовать прекращения обработки или удаления данных, если отсутствуют законные основания для их дальнейшего хранения.

Для реализации своих прав можно обратиться к Оператору по контактам, указанным в настоящей политике. Отзыв согласия может повлечь невозможность продолжения консультационной работы, если соответствующая обработка необходима для её организации.

Оператор принимает необходимые организационные и технические меры для защиты персональных данных от несанкционированного доступа, утраты и распространения. Рабочая информация используется исключительно в профессиональных целях.

При этом передача информации через интернет и сторонние цифровые сервисы не может гарантировать абсолютную безопасность. Для дополнительной защиты личной информации клиент может использовать псевдоним при записи и не направлять подробные сведения о своей жизни через незащищённые каналы связи.
